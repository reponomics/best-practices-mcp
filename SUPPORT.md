# Support

For installation and MCP host configuration, start with the [README](README.md). The [contributor guide](CONTRIBUTING.md) covers source installations, development connections and MCP Inspector. The [documentation index](docs/README.md) links to tool contracts, storage behavior and compatibility guidance.

Use [GitHub issues](https://github.com/reponomics/best-practices-mcp/issues) for usage questions, reproducible bugs, documentation corrections and suggestions. Search existing issues first. Include the server version, MCP host and version, operating system, and a small example when relevant. If possible, distinguish the tool's returned artifact from what the browser or host subsequently does with it.

Remove credentials, cookies, private draft content and unrelated personal information from logs and screenshots. Proposal URLs can contain complete draft answers; review them before sharing. Do not put vulnerability details in public issues or pull requests; follow the [security policy](SECURITY.md). For conduct concerns, use the private contact in the [Code of Conduct](CODE_OF_CONDUCT.md).

This repository supports the independent Reponomics MCP server. BadgeApp account access, badge decisions and website administration belong to the [upstream BadgeApp project](https://github.com/ossf/best-practices-badge). This project is not affiliated with OpenSSF, the Linux Foundation or BadgeApp. When uncertain whether a problem originates in the server, host or website, describe the observed behavior here without sharing account credentials.
