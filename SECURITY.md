# Security policy

## Supported versions

Reponomics provides security fixes for the latest stable release of Best Practices MCP. Until a stable release is available, the latest published beta is supported instead. Older releases do not receive backported security fixes; upgrade to the supported release.

## Report a vulnerability

Thank you for helping keep the project secure. Use [GitHub's private vulnerability reporting form](https://github.com/reponomics/best-practices-mcp/security/advisories/new). Reponomics maintainers monitor this inbox. Do not disclose vulnerability details in public issues or pull requests while coordination is underway.

Include the affected version, a description of the vulnerability and its impact, and minimal reproduction steps or a proof of concept. Remove credentials, cookies and unrelated private information. Reports about the MCP server, its generated artifacts, local draft storage, or distribution and release tooling belong here. Vulnerabilities in BadgeApp itself should follow the [upstream project's security policy](https://github.com/ossf/best-practices-badge/security/policy).

## Response and remediation

We will provide an initial response within 14 calendar days of receiving a report and remediate confirmed vulnerabilities affecting supported versions within 60 calendar days of receiving the report. We will coordinate the fix, release and disclosure with the reporter through the private report. If remediation is delayed, we will explain the reason, available mitigations and revised schedule there.
