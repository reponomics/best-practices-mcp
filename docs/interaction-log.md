# MCP interaction log

A working record of real interactions with best-practices-mcp. The intended direction is to let users voluntarily share their experiences, potentially through a GitHub issue template; the reporting format and contribution process are still open.

Each row records one session, its badge level, and a brief account of what worked or where difficulties occurred. Notes describe observed or reported behavior, not general certification of the MCP or the project's compliance. Where available, include the MCP version and a link to a fuller record in the note. Use the interaction date in YYYY-MM-DD format.
