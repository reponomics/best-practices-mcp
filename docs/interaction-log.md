# MCP interaction log

A working record of real interactions with best-practices-mcp. Users can voluntarily [share an experience through the prototype issue form](https://github.com/reponomics/best-practices-mcp/issues/new?template=usage_report.yml). Entries are self-reported; a brief description is enough. The reporting format can evolve as we learn what is useful.

Each row records one session, its badge level, and a brief account of what worked or where difficulties occurred. Notes describe observed or reported behavior, not general certification of the MCP or the project's compliance. Where available, include the MCP version and a link to a fuller record in the note. Use the interaction date in YYYY-MM-DD format.
